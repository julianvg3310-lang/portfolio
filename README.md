# Portafolio de Fotografía - Julián García

Portafolio minimalista de fotografía profesional con categorías de Eventos, Automotriz, Sesiones Privadas y Gastronomía.

## Características

✅ Diseño minimalista y limpio
✅ 4 categorías de fotografía
✅ Galería interactiva
✅ Información de contacto
✅ WhatsApp integrado
✅ Responsive (mobile-friendly)
✅ SEO optimizado

## Tecnologías

- Next.js 14
- React 18
- Tailwind CSS
- JavaScript

## Instalación

```bash
# Clonar repositorio
git clone https://github.com/julianvg3310-lang/portfolio.git
cd portfolio

# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev
```

Luego abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## Estructura de Carpetas

```

├── package.json

```

## Próximos Pasos

1. Añade tus fotos reales en la carpeta `public/images/`
2. Actualiza los datos en los componentes
3. Personaliza colores en `tailwind.config.js`
4. Deploy en Vercel o tu hosting preferido
